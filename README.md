# Expo Cross-Platform Productivity App

Connected Devices & Applications — Module 1

## Project Overview

This project is a cross-platform productivity application built with Expo and React Native.

The app will target both iOS and web platforms and will demonstrate core Module 1 concepts including task management, local data persistence, cross-platform configuration, and responsive design.

## Tech Stack

- Expo SDK 55
- React Native
- TypeScript
- Expo Router

## Target Platforms

- iOS
- Web

## Current Status

Initial Expo project scaffold created and verified successfully on:

- Web
- iOS Simulator

Additional assignment features, storage, styling, testing notes, and setup instructions will be added as development progresses.
